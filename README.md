# BS Factory – Webseite für B2B-Anfragen

Die Webseite liegt unter https://bsfactory.de/. Die Domain bleibt bei INWX; GitHub Pages stellt die Dateien bereit.

## Einfach weiterarbeiten
- Texte und Produktideen: `index.html`
- Farben, Abstände und Handyansicht: `style.css`
- Produktfilter: `site.js`
- B2B-Gestaltung: `b2b.css`
- Anfragevorbereitung: `anfrage.js`
- Kontaktdaten: `index.html`, `impressum.html`, `datenschutz.html`
- Bilder und Logo: die Bilddateien im gleichen Ordner
- Domain-Zuordnung: `CNAME` bitte beibehalten

Es ist keine Installation und kein Bauvorgang nötig. Änderungen an den Dateien im GitHub-Hauptzweig `main` werden von GitHub Pages veröffentlicht (Ordner `/ (root)`). Vor Änderungen eine Kopie aufbewahren. GitHub speichert außerdem frühere Versionen.

## Inhaltlicher Stand
Der Schwerpunkt liegt auf Firmenkunden: Teamwear, Firmenkleidung, Werbeartikel, Geschenksets, Schilder und Sonderideen. Große Stückzahlen, Größenmix, Varianten und Nachbestellungen können angefragt werden. Alle Mengenbeispiele sind Anfrageideen, keine bestätigten Kapazitäts- oder Terminzusagen.

Das Formular bereitet eine E-Mail vor; es verschickt selbst nichts. Der Besucher öffnet die fertige Nachricht in seinem E-Mail-Programm oder kopiert den Text in sein Postfach. Das Logo kann er dort anhängen. Es werden kein Formularanbieter und keine Kundendatenbank benötigt.

Das B2B-Titelbild zeigt die BS-Factory-Marke auf einer mit KI visualisierten Kollektion. Es ist als Konzept und nicht als Kundenreferenz gekennzeichnet. Die Startseite enthält keine Herkunftsgeschichte und keinen Ortsbezug. Die notwendige Anschrift bleibt in den Rechtstexten.

Zusätzlich gibt es vier kleinere Gestaltungsbeispiele: Herzensmensch basiert auf einem echten Muster; Reisezeit, Berglinie und Kapitelpause sind ungeprüfte Entwürfe. Es werden keine aktiven Etsy-Artikel vorausgesetzt und keine Preise veröffentlicht.

Bevor der Verkauf startet: Material, Maße, Preise, verfügbare Mengen und Bearbeitungszeiten am echten Produkt bestätigen; geschäftlichen Status und Verkaufspflichten klären. Danach können die öffentlichen Texte passend zum tatsächlichen Stand aktualisiert werden. Die enthaltenen Rechtstexte sind keine individuelle anwaltliche Prüfung.

Die bestätigten Kontaktdaten sind eingetragen. Keine Analysewerkzeuge, Werbedienste, externen Schriften oder eingebetteten Plattformen. Datenschutz berücksichtigt GitHub Pages und E-Mail-Kontakt.
